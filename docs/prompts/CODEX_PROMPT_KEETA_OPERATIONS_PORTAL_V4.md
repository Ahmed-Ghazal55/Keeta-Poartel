## 1) حاسبة الراتب والعمولة
المدخلات:
- نوع المركبة: سيارة / دباب.
- مصدر المركبة: شركة / خاصة.
- عدد الطلبات.
- أيام العمل الفعلية.
- أيام وجود المركبة مع المندوب.
- عدد أيام الشهر.
- أيام الصلاحية من 7.
- مستوى تجربة التوصيل A/B/C/None.
- السكن، السلف، الخصومات والتحملات الأخرى.
- سعر الطلب الافتراضي 6.5 ريال.
- سعر الكيلو الافتراضي 0.60 ريال.
- متوسط مسافة السيارة 8.5 كم.
- متوسط مسافة الدباب 3.5 كم.

المعادلات:
- عائد الطلب = 6.5 + (متوسط الكيلومترات × 0.60).
- السيارة = 11.60 ريال تقريبًا للطلب.
- الدباب = 8.60 ريال تقريبًا للطلب.
- إجمالي عائد الطلبات = عدد الطلبات × عائد الطلب.
- عمولة الشركة الشهرية = 2500 ريال.
- العمولة النسبية = 2500 ÷ عدد أيام الشهر × أيام العمل.
- إيجار السيارة = 1800 ÷ عدد أيام الشهر × أيام وجود السيارة.
- إيجار الدباب = 800 ÷ عدد أيام الشهر × أيام وجود الدباب.
- السكن = 200 ÷ عدد أيام الشهر × أيام السكن.
- الصافي = عائد الطلبات + حافز الصلاحية + حافز تجربة التوصيل - العمولة - الإيجار - السكن - السلف - الخصومات الأخرى.

قاعدة الصلاحية:
- حافز الصلاحية يصرف فقط في حالة الصلاحية.
- إذا المندوب غير صالح: حافز الصلاحية = 0 وحافز تجربة التوصيل = 0.
- الحد الأدنى: سيارة 330+، دباب 350+.
- شرط الأيام: صالح في 6 أيام من أصل 7 أيام إلزامية.

حوافز الصلاحية:
السيارة:
A: 600+ = 2600، B: 500-599 = 2100، C: 415-499 = 1800، D: 330-414 = 1200، E أقل من 330 = 0.
الدباب:
A: 650+ = 2000، B: 550-649 = 1200، C: 450-549 = 1000، D: 350-449 = 600، E أقل من 350 = 0.

حافز تجربة التوصيل:
A أعلى 30%: سيارة 2000 / دباب 1200.
B الـ55% التالية: سيارة 1500 / دباب 800.
C الـ15% الأخيرة: سيارة 1000 / دباب 400.

## 2) توزيع الشفتات — تنفيذ كامل

### إدخال الأيديهات
داخل صفحة توزيع الشفتات يوجد قسم:
`قائمة اليوزرات / الأيديهات المراد توزيعها`

المطلوب:
- Textarea للصق الأيديهات.
- Upload input لقبول `.csv` و `.txt`.
- زر قراءة الأيديهات.
- زر مسح القائمة.
- Status box يعرض عدد الأيديهات غير المكررة وعدد التكرارات المستبعدة.
- عند قراءة القائمة يتم تحديث إجمالي المناديب تلقائيًا.
- نتائج التوزيع يجب أن تستخدم User ID الحقيقي.
- إذا لا توجد أيديهات يستخدم النظام Rider 1 / Rider 2.

صيغ الإدخال:
- ID واحد في كل سطر.
- CSV فيه عمود user_id أو rider_id أو courier_id أو id أو الايدي أو معرف.
- CSV بدون Header: استخدم أول عمود أو القيم الصالحة.
- إزالة التكرارات تلقائيًا وعدم اعتبار Header كأيديهات.

### إعدادات الشفتات
- 6 شفتات:
  1. Shift 1: 12 AM - 3 AM
  2. Shift 2: 3 AM - 8 AM
  3. Shift 3: 8 AM - 12 PM
  4. Shift 4: 12 PM - 4 PM
  5. Shift 5: 4 PM - 8 PM
  6. Shift 6: 8 PM - 12 AM
- لكل شفت: Target و Max.
- Default: 3 شفتات لكل مندوب.
- ممنوع تجاوز Max.

### Engine التوزيع
ادمج منطق V11 وXLSM:
- كل مندوب يأخذ 3 شفتات.
- أولوية التركيبات:
  1. Back to Back
  2. 1 Gap
  3. 2 Gap
  4. 1 Gap + 1 Gap
- Scoring:
  - اختَر الشفتات الأقل تغطية مقابل Target.
  - امنع أي تركيبة تتجاوز Max.
  - قلل العجز العام.
  - قلل الفجوات.
- عند نقص المناديب: أفضل تغطية بدون تجاوز.
- عند زيادة المناديب: الباقي في جدول غير موزعين.

### نتائج الشفتات
اعرض:
- إجمالي الأيديهات المدخلة.
- عدد الموزعين.
- عدد غير موزعين.
- إجمالي Target.
- إجمالي Assigned.
- جدول Shift Summary.
- جدول Rider Assignment: user_id / shift_1 / shift_2 / shift_3 / shifts_text / combination_type.
- جدول Unassigned إن وجد.

### Export
- Export CSV للتوزيع.
- Export CSV لملخص الشفتات.
- Copy Results.
- CSV لازم UTF-8 BOM ليعمل في Excel.

## 3) توزيع المركبات
- Upload للمركبات، المناديب، الفروع، Operating Vehicles.
- Operating Vehicles مصدر الحقيقة.
- الرقم التسلسلي للمركبة مفتاح أساسي.
- منع المركبة غير التشغيلية.
- منع خلط المدينة.
- منع خلط السجل إلا باتفاقية.
- السيارة حدها 2 يوزر.
- الدباب حدّه 3 يوزرات.
- الدبابات على البوابة فقط.
- نقل عام فقط للداشبورد إذا القاعدة تتطلب ذلك.
- تقرير: مقترح التسجيل، سبب الرفض، سبب التثبيت، الكاباسيتي، المركبات المتاحة، المركبات الممتلئة، المستخدمين غير الموزعين.
