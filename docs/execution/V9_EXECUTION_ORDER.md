# V9 Execution Order — ترتيب التنفيذ الآمن

## الهدف
تنفيذ كل التعديلات فورًا لكن بدون كسر المشروع.

## الترتيب
1. راجع آخر تنفيذ وتقاريره.
2. شغل الاختبارات الحالية.
3. اربط الموديولات الحالية بالواجهة.
4. أضف صفحة Data Import Center إن لم تكن موجودة.
5. أضف صفحة Monthly Closing.
6. أضف monthlyClosingEngine.
7. أضف تحليل فواتير الشركة الأصلية.
8. أضف تحليل ملف التسوية الداخلي.
9. أضف مطابقة Company vs Internal.
10. أضف Final Monthly Settlement.
11. أضف Monthly Archive.
12. اربط الإقفال الشهري بحاسبة الراتب.
13. أضف Export Center لتقارير نهاية الشهر.
14. أضف Tests.
15. شغل كل الاختبارات.
16. نفذ مراجعة الملفات غير المهمة.
17. أرشف/احذف غير المهم بعد التأكد.
18. حدّث كل تقارير Markdown.

## لا تعمل
- لا تعمل Rewrite كامل.
- لا تحذف قبل Audit.
- لا تترك الموديولات بدون UI.
- لا تخلط جدة والرياض.
- لا تعتبر الحساب الداخلي أقوى من فاتورة الشركة النهائية.
