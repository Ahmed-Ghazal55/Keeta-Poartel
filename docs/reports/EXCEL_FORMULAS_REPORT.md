# Excel Formulas Report

## الحالة الحالية

- ملف المرجع المطلوب في البرومبت: `Updata_Vehicles (5).xlsx`
- وجوده داخل مساحة العمل الحالية أثناء التنفيذ: `غير موجود`
- النتيجة: لم يتم الادعاء بمراجعة Workbook غير متاح، وتم بناء صفحة مراجعة Excel لرفع الملف لاحقًا واستخراج الصيغ الفعلية عند توفره.

## ما تم تحويله إلى JavaScript

تم تحويل المنطق التشغيلي المؤكد من البرومبت إلى Functions مستقلة داخل `keeta_operations_portal_logic.js`:

- `prorateMonthlyAmount`
  لتوزيع العمولة والإيجار والسكن نسبيًا حسب أيام الشهر والأيام الفعلية.
- `getValidityTier`
  لتحويل سلالم حوافز الصلاحية للسيارة والدباب.
- `getExperienceIncentive`
  لتحويل مستويات `A / B / C / None` إلى حوافز تجربة التوصيل.
- `isOperationalStatus`
  لتحويل منطق استبعاد المركبات غير التشغيلية إلى دالة صريحة.
- `assignVehicles`
  لتحويل قواعد المطابقة بالسيريال والمدينة والسجل والسعة والنقل العام/الخاص إلى محرك توزيع وتحذير.

## ما تفعله صفحة مراجعة Excel

عند رفع أي ملف `XLSX / XLS` من داخل البوابة:

- تستخرج أسماء الأوراق.
- تحسب عدد الصفوف والأعمدة.
- تعرض Preview للمعادلات المكتشفة.
- تستخرج مجموعة Functions مقترحة للتحويل حسب أنماط مثل:
  - `IF`
  - `COUNTIF / COUNTIFS`
  - `SUMIF / SUMIFS`
  - `VLOOKUP / XLOOKUP`
  - `IFERROR`

## سياسة التعارض

إذا ظهر لاحقًا تعارض بين CSV وExcel، فالمطلوب في البوابة هو:

- عرض `warning` واضح.
- عدم التخمين.
- ترك القرار النهائي للمستخدم أو للمرجع التشغيلي المعتمد.
