# Shift Scheduler Reference Notes

## Scope in Prompt 8

Prompt 8 does not implement Prompt 9 scheduler integration.

It only keeps the scheduler as a documented reference area and registered placeholder template.

## Reference files

- `Shift Scheduler - Intelligent Rider Assignment.html`
- `Keeta Shifts Scheduling Tool V1.2 (3-Shifts) - AD (2).xlsm`

## Current registry status

The template registry includes:

- `shift_schedule`

The template is intentionally placeholder-level in Prompt 8 so the import registry can recognize the area without pretending the scheduling engine is finished.

## Design/logic direction carried forward

The scheduler references should preserve future support for:

- 5-shift mode
- 6-shift mode
- Ramadan mode

## Out of scope for Prompt 8

- XLSM macro recreation
- final shift allocation engine replacement
- Prompt 9 scheduler integration
