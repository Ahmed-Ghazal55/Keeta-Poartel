How to use (for Partners)

  • Step 1: Enter total active couriers.
  • Step 2: Paste courier IDs (one per line OR comma separated).
  • Step 3: Fill Min & Max for each shift.
  • Step 4: Click RUN PLAN.
  • Rules:
    • Every courier will get exactly 3 shifts (if feasible).
    • System will never exceed Max.
    • System tries to reduce gaps: consecutive first, then 1-break, then larger gaps only if needed.
    • V11 Fix: If total supply is low (couriers × 3 < Sum(Min)), tool builds a balanced target and then runs an optimizer to reduce slot imbalance (avoid “very low / zero” shifts when possible).
