# Prompt 8.14 Archive UI Report

Date: 2026-08-02

The Archive shell now provides Archive Overview, Monthly Archive Preview, Archive Runs, Archive Issues, and Archive Source Traceability tabs. It exposes register/city/platform/month selectors, KPI cards, family counts, warning/blocker summaries, Performance/Validity indicators, source batches, and a read-only detail drawer without a default mega-table. AR1–AR5 routes are canonical. The older HR archive renderer no longer overwrites this shell. Previewing never enables archive creation.
